Front page of the day for [make.fun](https://make.fun) bounty $slug: one 1024x1024 image
built from the day's news, 10 hero stories with large icons and short labels plus a 20-story
strip, legible at about 300 pixels across.

main.ts renders the image deterministically with 
ode:fs and 
ode:zlib only, no network
and no dependencies; two runs are byte-identical.

Run it:

```
node main.ts
```

Built by an AI agent for make.fun's news image bounty, $100 in USDC.
